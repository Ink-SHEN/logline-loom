## 注意事项（踩过的坑）
- **在本机用 `nohup ... &` 起的后台进程会被随后一条 Bash 命令的进程组回收一起干掉**（PID 38780 就这么没的）→ 必须用 Bash 工具的 `run_in_background=true` 托管
- `cmd //c start` 在 Git Bash 下被 MSYS 路径转换搞坏，别用
- PowerShell 工具的 stdout 会被吞，要 `Out-File` 落盘再 Read；`ps -W` 看不到 Git Bash 起的进程
- `LOOM/.workbuddy/` 会被清掉，写记忆前先 `mkdir -p`

AI+∞ 开发者创作大赛 · 电影 Agent

LOOM · 一句话生成一部 AI 短片

你只需写一句「一句话故事」，LOOM 会自动让 7 个分工明确的 Agent 接力把它一步步变成剧本、镜头、提示词，并尝试在 DGX Spark 上真生成成片。

在线体验www.modelscope.cn/studios/Incion/LOOM
1

它是什么？

LOOM 是一个「电影智能体」——不是聊天机器人，而是一条帮你把一句话变成一部短片的自动化产线。

① 片约你写一句话
›
② 编剧扩成完整剧本
›
③ 分镜拆成 6–8 个镜头
›
④ 提示词写 AI 生成指令
›
⑤ 生成跑出镜头视频

每走一步，中间产物（片约 / 剧本 / 分镜 / 提示词）都会在页面下方存成一份 JSON「契约」，随时可查、可反查。

2

三步上手

在左边输入框写一句话故事

20–400 字都行。越具体越好——告诉它主角、处境、转折。

点蓝色「开始生成」按钮

右边状态栏会像流水线一样，一站一站往下跳。

看 5 个标签页的产物

片约、剧本、分镜、提示词逐段出来，最后「生成结果」给你镜头视频。

3

每个输入框什么意思

控件填什么 / 什么意思
一句话故事（logline）唯一必填。20–400 字的一句话剧情。例：「一位独自值守射电望远镜的夜班技师，在最后一个班次收到一段来自自己未来的信号。」
目标时长（秒）整部片子想要多长，默认 150 秒（滑杆 60–300）。
画幅16:9 横屏 / 1:1 方屏 / 9:16 竖屏，默认 16:9。
视觉风格（可留空）想要的美术基调，如 「冷蓝调赛博朋克夜景」。留空则 AI 自定。
声音风格（可留空）配乐 / 氛围方向，如 「低沉环境音」。
自动批准人工关口默认勾选。演示模式下自动放行编剧关口，让全流程一次跑通。取消则会停在「② 剧本」等人工确认。
离线模式默认不勾。勾了就不调 AI，只看管线形状（排障用）。
4

看懂生成结果（重要）

最后这一步有两种可能，LOOM 都会诚实标注——绝不悄悄用旧视频冒充实时生成：

实时真生成本机 DGX Spark 在跑

状态栏显示「已连通 cuda…」。这是把提示词送去你本地 Spark 上的 MiniMax-H3 真跑。单个镜头要 6–12 分钟，所以不会干等你——提交后立刻返回一个「任务 ID」，参考预览先放着，稍后用「查询生成任务」区把 ID 粘进去取回成片。

预生成回放隧道暂不可达

状态栏会明确写「本次为预生成回放」。当你的 Spark 没开机 / 隧道断开时，LOOM 播放之前真实生成好的几个镜头让你先看效果，但会清清楚楚告诉你这不是本次生成的。开机后自动切回实时。

5

页面下方两个折叠面板

「隧道状态」

展示创空间能不能连上你本地的 DGX Spark（回源链路）。显示「已连通」就说明真生成后端在线；显示「地址失效 / 不可达」就是 Spark 那边没起来或隧道断了。按「重新解析隧道地址」可让它重新探一次。

「查询生成任务」

真生成是异步的，一个镜头要好几分钟。把刚才提交后拿到的「任务 ID」粘进来点「查询」，就能看进度；生成好了它会帮你把成片取回并播放。

💡
一个镜头 6–12 分钟是正常的——MiniMax-H3 在本地 GPU 上逐帧渲染。趁这个时间你可以继续生成下一个镜头。
6

常见问题（快速排查）

现象原因 & 怎么办
生成停在「② 编剧」不动检查是否取消了「自动批准人工关口」——取消后需在剧本确认后手动放行。
显示「本次为预生成回放」Spark 没开机或隧道断了。把本机 Spark 打开（crontab 会自动拉起链路），点「重新解析隧道地址」。
点开始没反应 / 停在等待创空间容器可能在休眠（长时间没人访问会睡）。刷新页面唤醒，等它自动重启再点。
查询任务显示「已排队」很久GPU 在上一个任务。等一下再查，会轮到你。
容器重启后任务 ID 查不到任务记录存在容器内存，重启会清空。重新提交一次即可。
7

几个要记住的事

  • logline 决定上限。一句话越具体，后面剧本和镜头越像那么回事。
  • 镜头数是 6–8 个，这是有意的——每个都要送真生成，太多整条线跑不完。
  • 「自动批准」勾上是看全流程最省事的方式；想体验人工关口就取消。
  • 别被「回放」吓到——它是诚实标注的演示机制，Spark 一开机就切回实时真生成。

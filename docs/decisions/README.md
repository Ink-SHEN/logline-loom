# docs/decisions/

决策记录（ADR）。**每条决定连同它的依据与当时的已知信息一起存档。**

---

## 为什么要存这个

五天赛程里会做几十个决定，其中一部分会在两天后被推翻。
如果只留最终结论，后来的人（包括评审、包括三个月后的自己）无法判断
**这个决定在当时是否合理**，也无法在类似情形下复用同样的推理。

所以规矩是：**不删旧记录，只追加新的。** 决定变了就写一条新的，
在新记录里指明它推翻了哪一条。

---

## 命名

```
YYYY-MM-DD-<短横线小写标题>.md
```

日期用**做决定的那天**，不是写文档的那天。

## 一条记录该包含什么

不强制模板，但这四件事要有：

1. **决定是什么** —— 一句话能说完
2. **当时的已知信息** —— 包括后来被证明是错的假设。这一项最容易被省略，也最值钱
3. **备选方案与为什么不选** —— 只写选中方案，等于没写
4. **什么条件下该重新审视它** —— 比如「若 R2V 冒烟测试失败，则第 4 项的分批策略要重排」

`2026-09-04-kickoff.md` 是这套写法的样例：它保留了会前的原始判断
（「Day 1 必须测出单镜头耗时，现在谁都不知道」），
也用 `▶` 保留了当晚推翻它的实测数据，两者都在。
